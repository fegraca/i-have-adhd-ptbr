# i-have-adhd (pt-BR)

Skill para Claude Code que formata as respostas para quem tem TDAH: começa pela próxima ação, numera etapas, reafirma o progresso a cada turno, corta tangentes e dá estimativas de tempo concretas.

Adaptação em português do Brasil de [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd) (v0.4.1).

## Instalar

```bash
git clone https://github.com/fegraca/i-have-adhd-ptbr.git ~/.claude/skills/i-have-adhd
```

Depois, `/i-have-adhd` carrega as regras. Para deixar sempre ativa, cole um resumo das regras no seu `~/.claude/CLAUDE.md` apontando para `~/.claude/skills/i-have-adhd/SKILL.md`.

## Desligar

Na sessão: "stop adhd mode" ou "modo normal".
